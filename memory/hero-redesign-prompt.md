# Промт для Claude Code: минималистичный херо со спиральным полётом

Работай в существующем проекте D:/Сайты/Портфолио. Сначала прочитай актуальные AGENTS.md и .claude/CLAUDE.md. Не меняй стек: React + Vite + TypeScript, Three.js для сцены, три локали ru/en/de.

Контекст: в рабочем дереве уже есть реализация этого направления. Сначала изучи diff и проверь её в браузере; развивай существующее решение, не перезаписывай чужие изменения. Боевой сайт https://pavellevdin.ru может отличаться от локального кода.

Главная задача — сделать херо красивым, спокойным и минималистичным, сохранив выразительную спираль при прокрутке. Прежняя версия ощущалась как семь карточек на космическом фоне. Нужен плавный полёт в глубину, где сама спираль и типографика создают впечатление.

Первый экран:
- Один короткий двухстрочный заголовок: «Создаю сайты. / Соединяю системы.»
- Небольшая подпись «Павел Левдин · веб-разработчик».
- Короткий лид: «Дизайн, разработка, SEO и автоматизация — от первой идеи до запуска.»
- Основная кнопка «Обсудить проект» и вторичная текстовая ссылка «Смотреть работы».
- Много воздуха. Локальный Golos Text для заголовков и текста, JetBrains Mono только для технологических подписей. Тёмный фон #060810, спокойный синий #7AA2FF.
- Убрать badge, длинные обещания, блестящий текст, несколько конкурирующих акцентов.

При прокрутке:
- Полностью убрать карточки семи шагов, их изображения, нумерацию и пагинацию.
- Оставить одну выразительную тонкую спираль и слабую вторую нить.
- TypeScript, JavaScript, React, Node.js, SQL, HTML, CSS появляются прямо в пространстве без рамок, плашек, описаний и логотипов. Это технологии, не все из них языки программирования.
- Слова приближаются из глубины, увеличиваются и мягко уходят за край. Одновременно видны примерно 2–3 названия разного масштаба.
- Подписи и спираль используют одну перспективную камеру. Не заменять это последовательным fade одинаковых блоков.
- Звёзды — редкие мягкие мелкие точки, без крестов, вспышек, повторяющейся текстуры и крупных ореолов.
- Нельзя отключать анимацию из-за высоты или ширины окна: она должна работать и на ноутбуке 1366×650, и на телефоне 375×667. На низких экранах адаптируй композицию и длину вступления.
- Нативная прокрутка без перехвата wheel. Обратная прокрутка восстанавливает сцену. Предусмотреть переход сразу к работам.

Остальной сайт:
- Убрать повторяющиеся декоративные звёздочки, сияющий курсор, магнитные кнопки и наклон карточек.
- Услуги оформить спокойной типографикой и тонкими разделителями. Не дублировать смысл одновременно картинкой, иконкой и номером.
- В интеграциях оставить одну понятную схему.
- Сохранить реальные скриншоты проектов, фотографию Павла, контент, контакты, формы, SEO и все локали. Не добавлять выдуманные достижения.

Основные файлы: src/sections/scena/SceneSection.tsx, scene-gl.ts, scene-model.ts, scene.css; src/styles/pl.css; src/components/pl/ServicesGrid.tsx и Integrations.tsx; src/i18n/locales/{ru,en,de}.json.

Приёмка:
1. Проверить desktop 1440×1000, mobile 390×844 и 375×812, низкий экран 1280×600, все три языка.
2. Снять начало и несколько промежуточных кадров скролла. Проверить отсутствие переполнения, наложений и обрезанных кнопок.
3. Проверить reduced motion, отсутствие JavaScript/WebGL, переключение motion-настройки, возврат вверх и якорь работ.
4. WebGL загружается отдельным чанком; нет непрерывного рендера в простое или скрытой вкладке. Ограничить DPR, освобождать обработчики и GPU-ресурсы.
5. Выполнить npm run build:static и lint. Отделить существующие ошибки вне diff от новых; не заявлять успешный полный lint, если он падает.
6. Показать скриншоты и описать проверенный результат. Не деплоить без явной команды Павла «деплой».
