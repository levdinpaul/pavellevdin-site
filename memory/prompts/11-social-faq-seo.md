- Выводим в порядке: Telegram, WhatsApp, YouTube, VK (если есть), почта. Иконки — inline SVG 20–22 px, `currentColor`,
  без сторонних icon-пакетов. Общий вид — как у текущих соц-иконок футера, бренд `--accent` при наведении.
- Поведение:
  - desktop (≥1024 px): `position: fixed; right: 12px; top: 50%; transform: translateY(-50%)`, вертикально, зазор 10 px,
    фон-«таблетка» `rgba(10,14,26,.72)` + `backdrop-filter: blur(8px)`, радиус 999px, тонкая рамка;

  - `prefers-reduced-motion` — без анимаций появления;
  - a11y: `<nav aria-label>` по локали («Социальные сети» / «Soziale Netzwerke» / «Social networks»), у каждой ссылки
    `aria-label` с названием, `rel="noopener noreferrer"`, `target="_blank"`, видимый `:focus-visible`;
  - на страницах платформы (блог, кабинет) панели нет — это другое приложение, не трогать.
