# Промпт 13 — упростить админку pl-platform под одного владельца

Репозиторий: `pl-platform` (папка `web/`, Next.js). Запускать из `D:\Сайты\pl-platform` (или где он лежит у Pavel).
Прочитай `.claude/CLAUDE.md` и `.claude/agents.md` репозитория.

## [Задача]
Pavel работает один, ему нужна минимальная админка `/ru/admin`: видеть заявки, отвечать, при необходимости делать КП,
модерировать отзывы, писать блог, смотреть одну сводку по трафику и SEO. Всё остальное убрать из меню и интерфейса.
Данные в базе НЕ удалять (миграций, DROP, чистки таблиц — нет): убираем только пункты меню и экраны. Маршруты можно
оставить рабочими по прямой ссылке или закрыть редиректом на `/admin`; решение — по меньшему риску.

### 1. Меню (`web/src/app/[locale]/(admin)/AdminShell.tsx`)
Оставить 6 пунктов, в таком порядке:
1. **Обзор** (`/admin`) — объединённая сводка, см. п. 4.
2. **Заявки** (`/admin/leads`) — бывшие «Лиды», см. п. 2.
3. **КП** (`/admin/angebot`) — коммерческие предложения (в меню называть «КП», не «Предложения»).
4. **Блог** (`/admin/blog`).
5. **Отзывы** (`/admin/reviews`) — упрощённо, см. п. 3.
6. **Настройки** (`/admin/settings`).

Убрать из меню: «Письма» (`/admin/brief`, письма на бланке, в базе 0 документов), «CRM-Задачи» (`/admin/crm-tasks`, 0 записей),
«Проекты» (`/admin/projects`, 0 записей), «Пользователи» (`/admin/users`), «Команда» (`/admin/team`), отдельный «SEO и Маркетинг»
(`/admin/seo`, переезжает в «Обзор»). Колокольчик уведомлений оставить только если он показывает новые заявки; иначе убрать.
Переключатель языка DE/EN/RU оставить, по умолчанию RU.
Блоки «CRM-задачи» внутри карточек заявок/проектов (`CRMTasksBlock`) скрыть.

### 2. Заявки (`admin/leads/page.tsx`)
- Колонки: Имя, Контакт (почта/Telegram/телефон), Сообщение (первые ~80 символов), Источник, Дата, Статус. Убрать `WA`, `CR`,
  `PRIORITY`, «NEW · 0» и прочие скоринг-колонки.
- Статусы упростить до: Новая / В работе / Закрыта (маппинг на существующие значения без миграции; старые значения
  отображать как ближайшие).
- **Удаление должно быть заметным**: кнопка-корзина в каждой строке (не только в раскрытой карточке), с подтверждением
  `AlertDialog` («Удалить заявку навсегда?»). Использовать существующий `DELETE /api/admin/leads`. Pavel сейчас не может
  найти, как удалить заявку.
- Фильтр по умолчанию — «Все» (сейчас «Новый», из-за чего легко потерять заявки).
- Проверить, что кириллица в именах/сообщениях отображается корректно (в базе уже есть тестовая заявка №4 с испорченной
  кодировкой — это мусор от консольной отправки, Pavel удалит её сам кнопкой).

### 3. Отзывы (`admin/reviews/page.tsx`, API не менять)
- Убрать блок со ссылками «проект × язык» (список всех сайтов и ссылок на ru/de/en) и связанный UI токенов.
  Бэкенд токенов и cron `review-requests-cron.sh` не трогать.
- Оставить: список отзывов с вкладками Ожидают / Опубликованы / Отклонены, кнопки Одобрить / Отклонить / Удалить / Править,
  и одну кнопку «Скопировать ссылку для клиента» → общая ссылка на форму отзыва на сайте (проверить, какой публичный URL
  формы существует без токена; если нужен токен — генерировать один общий без привязки к проекту/языку, язык = текущий).
- Блок «Импорт отзывов с площадок» (Kwork/FL/Habr/Google/Яндекс) свернуть в один сворачиваемый раздел «Добавить отзыв вручную».
- Не выдумывать отзывы и данные.

### 4. Обзор = Статистика + SEO + Маркетинг (`admin/page.tsx`, `admin/seo`, `components/admin/seo/*`)
Одна страница вместо двух. Сверху 4 карточки: Новые заявки / Всего заявок за 30 дней / Отзывы на модерации / КП в работе.
Ниже один график «Заявки по дням» и одна таблица «Источники заявок». Затем блок «Трафик и поиск».
Подключить ТО, ЧТО РЕАЛЬНО ЕСТЬ у проекта, остальное не показывать пустыми блоками:
- **Яндекс.Метрика** (счётчик сайта pavellevdin.ru): визиты, посетители, достижения целей (контакт, бриф, визитка и т.д.).
  Нужен OAuth-токен: ключ `YANDEX_METRIKA_TOKEN` + `YANDEX_METRIKA_COUNTER_ID` в `.env` платформы. Если ключей нет — показать
  аккуратную подсказку «Подключить Метрику» с инструкцией из 3 шагов, не ошибку.
- **Яндекс.Вебмастер / Google Search Console / Bing**: статус верификации и индексации — только то, что можно получить по
  имеющимся токенам. Если токена нет — одна строка «не подключено» со ссылкой на инструкцию.
- Блоки GA4, Buffer, Google Business Profile (`Ga4Stats`, `BufferStats`, `GbpInfo`) убрать из интерфейса (рынок РФ, они не
  подключены); код не удалять. Вкладку «Документация» заменить короткой памяткой «Как подключить ключи».
Никаких выдуманных цифр: нет данных → «нет данных».

### 5. Предложения (КП) — не удалять, но упростить
`/admin/angebot`: список КП (№, клиент, предмет, итого, статус, дата) + «Новое КП». Убрать терминологию Holzbau/MP из шаблонов и
подписей, если осталась. Добавить на странице одну строку-подсказку: «КП создаётся из заявки: откройте заявку → «Сделать КП»
→ PDF → отправить клиенту». Если кнопки «Сделать КП» в заявке нет — добавить (ведёт на `/admin/angebot/new?lead=<id>`).

### 6. Тексты
`web/messages/{ru,de,en}.json` — ключи синхронны во всех трёх. Названия в меню на RU: Обзор, Заявки, КП, Блог, Отзывы, Настройки.

## [Контекст]
- Платформа на russh (`/srv/sites/pavellevdin.ru/platform`, compose project `pl-prod`), образы `pl-web:pN`, сборка на VPS `ssh vps`
  (`~/pl-platform-build`), перенос `docker save | docker load`. Локальная сборка у Pavel падает из-за памяти — используй VPS.
- Тема только тёмная (см. `.claude/CLAUDE.md`): палитры tailwind зеркальные.
- Сейчас в базе: leads 1 (тест, мусор), angebot_versions 2, brief_documents 0, crm_tasks 0, configurator_requests 0.
- Версии Next/Strapi не писать по памяти — смотреть `package.json`.

## [Агенты]
Общие код-агенты репозитория; для текстов меню/подсказок на RU — `pl-copywriter-ru`. Финальную проверку интерфейса сделай
скриншотами (playwright) на 1440 и 390.

## [Готово когда]
- В меню 6 пунктов, нет «Письма / CRM-Задачи / Проекты / Пользователи / Команда / SEO и Маркетинг».
- В «Заявках» видна корзина в каждой строке, удаление с подтверждением работает, колонки упрощены, кириллица читается.
- В «Отзывах» нет списка проект × язык; есть модерация и «Скопировать ссылку для клиента».
- «Обзор» объединяет статистику и SEO; без ключей Метрики показывает подсказку, а не ошибку.
- `tsc --noEmit` в `web` без ошибок, три локали синхронны, скриншоты приложены.
- Образ собран на VPS; НЕ выкатывать на прод без слова «деплой» от Pavel. В конце — обновить LAST_SESSION и LEARNINGS.

## [Правила]
Отвечать Pavel по-русски. Данные в базе не удалять и не мигрировать. Не трогать `scripts/data/`, `.env` сайта, чужие сайты на
сервере. Телефон нигде не публиковать, адрес — только «Hannover, Germany». Резервная копия перед любой правкой на сервере.
