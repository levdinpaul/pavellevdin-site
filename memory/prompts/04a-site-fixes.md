## 5. Анимации — вернуть, чтобы было видно по всему сайту (без возврата «каши»)
Pavel хочет заметную живость. Вернуть аккуратно, всё с prefers-reduced-motion и только transform/opacity:
- Заголовки секций H2: появление по строкам (line-mask reveal, 700ms), вторая приглушённая строка — с задержкой 120ms.
- Reveal блоков со stagger 60–80ms (карточки проектов, услуги, отзывы, цены).
- Карточки проектов: лёгкий 3D-tilt ≤ 4° + блик (только pointer:fine), zoom скрина 1.03.
- Главная CTA-кнопка: магнитный эффект (pointer:fine), стрелка уезжает при hover.
- «Обо мне» и /about: count-up цифр (10+ лет, 11 проектов из данных, 3 языка) при появлении.
- /about: бегущая строка стека (из stack.ts, медленная, пауза при hover).
- Ссылки меню: подчёркивание выезжает слева направо.
- Переходы между страницами: View Transitions API (fade + лёгкий сдвиг), фолбэк — без анимации.
- Курсор-свечение — НЕ возвращать.
- Micro-UI из 03-hero-spiral-minimal.md §6 сделать сейчас (это главные «живые» элементы): окно браузера с Lighthouse 100
  (досчитывает), сниппет выдачи + JSON-LD, лог API печатается построчно, чат с AI и чипом MCP — в 4 колонках «Что я делаю»
  на главной и в услугах. Анимация запускается при появлении один раз.
Бюджет: Lighthouse главной mobile ≥ 80, desktop ≥ 95, CLS < 0.05, TBT не хуже текущего более чем на 100 мс.
