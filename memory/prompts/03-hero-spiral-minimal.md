## [Задача]
Pavel недоволен результатом 02: hero перегружен, вместо «спирали при прокрутке» получились карточки-блоки,
звёзды и сгенерированные «керамические» 3D-картинки не по теме. Нужно:
1. Новый hero — минималистичный, по эталону.
2. Спираль при прокрутке БЕЗ карточек шагов: камера летит сквозь спиральную галактику из тонкой пыли,
   навстречу плавно прилетают названия технологий (как звёзды из глубины).
3. Новая типографика и короткие заголовки.
4. Убрать сгенерированные картинки по всему сайту, заменить тематичными минималистичными визуалами.
5. Главная — меньше блоков, больше воздуха.

## [План]

### 0. Ветка `hero-v2` от main, тег `pre-hero-v2`.

### 1. Типографика (вся система)
- Шрифты: **Onest** (400/500/600, latin+cyrillic, variable woff2) — заголовки и текст; **JetBrains Mono** (400/500) —
  eyebrow, навигация, метки, цифры, названия технологий второго ряда. Self-host в public/fonts, preload только Onest 500.
  Golos Text удалить.
- Шкала: H1 `clamp(42px,7.4vw,112px)/0.98`, ls −0.045em, вес 500 · H2 `clamp(32px,4.6vw,64px)/1.04`, ls −0.035em, 500 ·
  текст 17px/1.6 · mono-метки 12px uppercase ls .14em цвет --ink-3. Максимум 2 веса на экран. Никакого жирного 700.
- Цвета текста: --ink #EEF1F8, --ink-2 #9AA3B8, --ink-3 #5C6478; акцент #7AA2FF — только точки, линии, мелкие метки.
  Приём «вторая строка заголовка приглушённая (--ink-3)» — фирменный, использовать во всех H1/H2.

### 2. Шапка (все страницы)

Убрать: боковую колонку соцсетей на главной (контакты остаются в футере и на /contact), прогресс-бар в шапке.
Фон шапки появляется только после hero (как сейчас), но без тени — только 1px линия --line.

### 4. Спираль стека — заменяет сцену из 7 шагов
- Компонент `StackSpiral` (canvas 2D, БЕЗ three.js). Перенести алгоритм эталона: пыль вдоль 2 рукавов спирали
  (тонкие точки 1–2.6px, без bloom/sprite-свечения), полёт камеры по z от прокрутки, инерция (lerp .085),
  медленное вращение, названия технологий прилетают из глубины по золотому углу, одновременно видно ~6–7,
  ключевые — Onest 500 светлые с акцентной точкой, остальные — JetBrains Mono приглушённые.
- Финал: «Весь стек / Один разработчик. Полный цикл.» по центру, затем обычный скролл к следующей секции.
- Высота секции: 420vh desktop, 320vh mobile. Sticky-кадр.
- Данные стека — `src/data/stack.ts` (единственный источник: имя, key, категория). Список из эталона = реальный стек Pavel,
  не добавлять ничего, чего нет в инвентаре/репо.
- SEO/доступность: canvas `aria-hidden`; в HTML (SSR) — visually-hidden `<ul>` со всем стеком и финальная фраза текстом.
- Перф: canvas монтируется после гидрации; rAF только пока секция в вьюпорте (IntersectionObserver) и вкладка видима;
  DPR ≤ 1.75; пыль 2000 desktop / 900 mobile; без аллокаций в кадре (ctx.font менять только при смене размера-бакета).
- prefers-reduced-motion: статичный кадр спирали + стек обычным списком в 3 колонки, высота секции auto.
- **Удалить three.js полностью**: scene-gl.ts, зависимость `three` из package.json, все импорты. Удалить 7 карточек шагов
  и их i18n-ключи. Смысл 7 шагов перенести в «Как я работаю» на /services (объединить с существующим процессом 01–05,
  без дублей).

### 5. Главная — меньше блоков
Порядок: Hero+Спираль → Работы → Что я делаю → Обо мне (кратко) → CTA → футер.
- **Работы**: eyebrow «Избранные работы», H2 «Живые проекты, / а не макеты.» 4 featured-проекта крупными карточками
  (2×2 на desktop, 1 колонка на mobile): реальный скриншот, название, одна строка, стек mono. Hover: лёгкий zoom скрина 1.03,
  без 3D-tilt и бликов. Ссылка «Все проекты →».
- **Что я делаю**: eyebrow «Что я делаю», H2 «От сайта / до автоматизации.» 4 колонки с micro-UI (см. п.6):
  Сайты и приложения · SEO и видимость · Интеграции и API · AI и автоматизация. Под каждой 2 строки текста.
  Полная сетка из 8 услуг и схема интеграций — переезжают на /services.
- **Обо мне**: фото (реальное) + «10+ лет в вебе. / Один подрядчик на всё.» + 2 предложения + «Подробнее →».
  Цифры-счётчики и бегущая строка стека с главной убрать (спираль их заменяет; цифры остаются на /about).
- **CTA**: «Есть задача? / Давайте обсудим.» + кнопка + Telegram/WhatsApp текстом.

### 6. Визуалы вместо сгенерированных картинок (весь сайт)
Удалить ВСЕ использования `public/images/site/*` (шаги, услуги, интеграции, about-workspace/path), компонент GenImage,
сами файлы из public. Исходники остаются в `_design/generated/` (вне git). Новые генерации НЕ делать.
Вместо них — тематичные **micro-UI** на HTML/CSS/SVG (монохром + акцент, рамка 1px --line, радиус 16, mono-шрифт внутри),
с тихой анимацией при появлении (один раз, 1–2 c, только transform/opacity), reduced-motion — статично:
| Где | Micro-UI |
|---|---|
| Сайты и приложения | мини-окно браузера со скелетом страницы + 4 круга Lighthouse, числа досчитывают до 100 |
| SEO и видимость | сниппет поисковой выдачи (заголовок, URL, звёзды rich result) + 3 строки JSON-LD |
| Интеграции и API | лог запросов печатается построчно: `POST /api/lead 201` → `telegram.sendMessage ✓` → `crm.createDeal ✓` |
| AI и автоматизация | 2 пузыря чата: вопрос → ответ ассистента с чипом вызова MCP-инструмента |
| /services: Боты | уведомление Telegram «Новая заявка с сайта» |
| /services: Инфраструктура | список контейнеров `next · strapi · postgres · nginx` с зелёными точками «up» (без выдуманных цифр) |
| /services: Соцсети | карточка запланированного поста + 3 иконки-точки площадок (без логотипов брендов) |
Тексты внутри micro-UI — обезличенные примеры, без реальных данных клиентов.
- /about: убрать 2 сгенерированных фона; оставить реальное фото, процесс, навыки — в новой типографике.
- OG-картинка: перегенерировать КОДОМ (не AI): тёмный фон, кусок спирали из пыли, H1 «Сайты и системы, которые работают.», mono-подпись.
